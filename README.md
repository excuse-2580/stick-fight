# 火柴人大战

单文件网页游戏，一个 HTML 搞定：启动页 → 选人 → 对战。

## 在线玩

https://excuse-2580.github.io/stick-fight/

## 玩法

- **选角色**：5 个火柴人，数值各不相同
  - 方火柴人：防御 +20%，血 120
  - 圆头火柴人：攻速最快，血 90
  - 长腿火柴人：跳得更高，移速 4.4
  - 胖火柴人：血厚 150、攻击重但慢
  - 独眼火柴人：暴击率 30%
- **操作**
  - 手机：屏幕上的 ◀ ▶ 移动、▲ 跳、拳 攻击
  - 电脑：`A`/`D` 移动、`W` 跳、`F` 出拳（方向键 + 空格也行）
- **胜负**：打光对手血条，或把对手击飞出屏幕

## 技术

纯原生 HTML + CSS + Canvas，无框架、无外部依赖、无网络请求。
路由走 `hash`（`#/` `#/select` `#/fight`），三屏在一个文件内切换。

## 说明

重力 0.8、击飞 8.5、拳速 9 等手感参数为经验值，非实测数据。
